# Archived documents

Superseded prose, kept rather than deleted because it is the record of what was
believed at the time and why. **Nothing here should be quoted.** For current
numbers see [`../OVERVIEW.md`](../OVERVIEW.md); for the method behind them, see
[`../methodology_explainer.md`](../methodology_explainer.md).

Two kinds of document end up here. *Dated records* were never meant to be
updated — they are accounts of a moment, and they went stale by design.
*Superseded working documents* were meant to be kept current, and were retired
once that stopped being true.
